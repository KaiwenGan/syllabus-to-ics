# 配置字段说明

顶层只有 9 个键，全部可选除 `term.first_monday`、`periods`、`courses`。

## calendar

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | string | `课表` | 导入后显示在日历列表里的名字，也是 `X-WR-CALNAME` |
| `description` | string | 空 | 日历描述 |
| `timezone` | string | `+08:00` | 事件时间的解释基准。`+08:00` 或 `Asia/Shanghai` 都行；**只在生成时用来换算 UTC**，不写进 ics |
| `location_prefix` | string | 空 | 拼在 `地点` 前面。如 `示例大学` + `主校区 教2楼205` → `示例大学 主校区 教2楼205` |
| `prodid` | string | 内置 | 日历产商标识，一般不用改 |

## term

| 字段 | 类型 | 说明 |
|---|---|---|
| `first_monday` | `YYYY-MM-DD` | **第一教学周的周一**。校历通常写"9 月 7 日—1 月 17 日共 19 周"，9/7 就是它。注意不是报到日、不是开学典礼日 |
| `weeks` | int | 学期总周数，用于报告里的逐周统计；超出范围的周次会被忽略 |

周次换算：第 N 周周一 = `first_monday + (N-1)×7`；第 N 周星期 k = `first_monday + (N-1)×7 + (k-1)`，`k` 取值 1–7。

## seasons

| 字段 | 类型 | 说明 |
|---|---|---|
| `winter_ranges` | `[[起, 止], …]` | 冬令时生效的「月-日」区间，支持跨年。`[["10-01","04-30"]]` 表示 10/1 到次年 4/30 用 `winter` 那套时间，其余用 `summer` |

留空或不写 → 全年用同一套时间（`periods` 里的 `summer` 与 `winter` 写一样即可，也可只写一次的简写形式 `"1-2": ["08:00","09:35"]`）。

**判定粒度是"天"**，不是"周"：切换日当天的课按新作息，所以同一自然周里周一可能还是夏令时、周四已经冬令时。这是正确行为——作息表就是按日历日执行的。

## periods

键是课表里的节次字符串，值是该节次的上课起止。

```json
"periods": {
  "1-2":  { "summer": ["08:00", "09:35"], "winter": ["08:00", "09:35"] },
  "3-4":  { "summer": ["09:50", "11:25"], "winter": ["09:50", "11:25"] },
  "6-7":  { "summer": ["14:00", "15:35"], "winter": ["13:30", "15:05"] },
  "8-9":  { "summer": ["15:50", "17:25"], "winter": ["15:20", "16:55"] },
  "10-12":{ "summer": ["19:00", "21:25"], "winter": ["18:30", "20:55"] }
}
```

- 键必须与 `courses[].period` **完全一致**（`"3-4"` 不等于 `"3~4"`）。对不上时 `build.py` 直接报错，不会猜。
- 如果学校按"每节独立"给时间，就写成 `"3-3"`、`"4-4"`，课程里也用 `"3-3"`。
- 跨中午的长时段（如 `3-5`）只需把起止填对，中间是否含午休不影响——课表给的是连续区间。

## holidays

| 字段 | 类型 | 说明 |
|---|---|---|
| `start` / `end` | `YYYY-MM-DD` | 含首含尾 |
| `name` | string | 报告里显示 |
| `skip_classes` | bool | 默认 `true`。为 `false` 时只记录不剔除（适合"放假但有课"的调休日） |

被剔除的课会在报告的「假期顺延」一节列出，方便核对是不是剔多了。

## courses[]

| 字段 | 必填 | 说明 |
|---|---|---|
| `weekday` | ✅ | `1`–`7`，或 `"周一"`/`"星期一"`/`"Mon"` |
| `period` | ✅ | 必须是 `periods` 里的键 |
| `name` | ✅ | 事件标题 |
| `weeks` | ✅ | 见下方语法 |
| `campus` | | 校区，如 `主校区` |
| `location` | | 教室，如 `教2楼205`。**"教2楼"是一个整体，不要拆成"教2 楼"**，否则地图检索会跑偏 |
| `teacher` | | 写进事件备注 |
| `note` | | 追加到备注末尾，如教学班、学分 |

同一天同一节次可以有多条（单双周轮换），`build.py` 会检测时间冲突并在报告里警告——注意单周/双周不算冲突，只有真的同一天同一时刻才报。

## weeks 语法

| 写法 | 含义 |
|---|---|
| `1-16` | 第 1 到 16 周 |
| `4-6周(双),7-17周` | 4、6 周，加上 7–17 全部 |
| `5周,9-15周(单)` | 第 5 周，加上 9、11、13、15 |
| `第17周` | 仅第 17 周 |
| `6周,9周` | 第 6、9 周 |
| `3,5,7` | 离散周次 |

分隔符支持 `,` `，` `;` `；` `、`；单双周标记支持 `(单)(双)(odd)(even)单周双周`。

## allday[]

| 字段 | 必填 | 说明 |
|---|---|---|
| `summary` | ✅ | 事件标题 |
| `start` | ✅ | `YYYY-MM-DD` |
| `end` | ✅ | `YYYY-MM-DD`，**含最后一天**（脚本内部转排他 `DTEND`） |
| `description` | | 备注。**写清依据**（校历第几条、课表哪一行），方便日后核对 |
| `location` | | 地点 |

全天事件不带钟点、不加 `-PT15M` 提醒——避免在凌晨响。

## alarm_minutes

课前提醒分钟数，默认 `15`。写 `null` 则完全不提醒。所有定时事件统一使用这个值；需要单条不同，目前需改 `icsgen.add_event` 的 `alarm_minutes` 参数。
